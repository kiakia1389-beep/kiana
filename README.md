# برنامهٔ درسی کیانا

اپلیکیشن برنامهٔ هفتگی دانش‌آموز یازدهم تجربی: داشبورد، ایام هفته، درس‌ها، هفته‌ها تا پایان سال، یادآوری امتحان، نمرات و آمار.
بدون سرور و بدون اینترنت (پس از اولین باز شدن) کار می‌کند. اطلاعات داخل مرورگر ذخیره می‌شود.

## اجرا
- **روی GitHub Pages:** آدرس صفحه را باز کنید. در Chrome یا Edge دکمهٔ نصب (Install) کنار نوار آدرس ظاهر می‌شود و برنامه مثل اپ جدا باز می‌شود و آفلاین هم کار می‌کند.
- **مستقیم روی کامپیوتر:** فایل `index.html` را با دوبار کلیک باز کنید.

## پشتیبان‌گیری
دکمهٔ «ذخیرهٔ پشتیبان» بالای صفحه یک فایل JSON می‌سازد. با «بازیابی پشتیبان» می‌توان آن را به مرورگر یا کامپیوتر دیگر برد.

## فونت‌ها (اختیاری)
راهنما در `fonts/README.txt`.
